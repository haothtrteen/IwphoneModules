安装方式

1

在 App 内安装（推荐）

打开 IWPhone → 模块 → 云模块库，点模块右侧的「安装」。App 会自动下载并校验 SHA-256。

2

下载 .iwp 手动安装

在本页点「下载」，把文件放到手机 /sdcard/iwphone/，然后在 App 的模块页选择本地安装。

3

校验完整性

每个模块都列出 SHA-256。手动下载后可用 sha256sum 文件.iwp 对照，不一致就不要装。

提交模块

仓库已改为「源码即模块」结构，提交时不需要手工改清单。

modules/
└── 你的模块名/
    ├── module.json     # 元数据：id / name / version / author / description / category
    ├── main.sh         # 入口（Magisk 兼容模块可用 service.sh）
    ├── iwphone.prop
    ├── config.prop     # 可选，带配置界面的模块需要
    └── uninstall.sh    # 可选

把目录 push 到 main 分支后，GitHub Actions 会自动打包 .iwp、计算 SHA-256、重建 modules.catalog.json 并更新本页。

注意：module.json 与 README.md 不会被打进 .iwp；.sh 会保留可执行位。
