# Shell Manager v1.3.0

免 root 的 Android 模块管理器：不刷机、不解锁 Bootloader，通过系统自带的无线调试取得 shell 权限，
再用一套自带运行时 + 沙箱 + 写前快照的框架来跑各种免 root 模块。**从配对到部署全程在手机内完成，不需要电脑。**

---

## 本次更新（v1.2.3 → v1.3.0）

### 修复

- **首页空白 / 点按钮报「WebUI 不可达」** —— 这是最影响使用的一个问题。两个独立原因：
  一是守护进程还活着时，启动流程会提前 `return`，后面拉起 WebUI 的代码永远不执行；
  二是 WebUI 的启动命令没做会话脱离，adb 会话一断开就被连带杀掉。
  现在两条分支都会确保 WebUI 在跑，并且加了 `setsid -d`。
- **WebUI 看护** —— 守护进程每轮检查 WebUI 是否存活，掉线约 1 分钟内自动重拉。
  开机自启只拉起守护进程，也会把 WebUI 带起来。
- **模块卸载残留** —— 模块把产物放到 `work/` 之外时（例如 `应用管理aapt` 把二进制拷到
  `/data/local/tmp/aapt`）永远清不掉。现在卸载前会尽力执行一次模块自带的 `uninstall.sh`，
  失败只记录、不影响主流程。
- **`应用管理aapt` 卸载路径写错** —— `work/aapt` 修正为 `work/应用管理aapt`
  （模块目录名取 `.iwp` 文件名主名）。
- **首次激活的三个问题** —— 未设访问密钥不再阻断使用；设置密钥不再报
  `failed to get feature set`；引导流程按框架进程是否存在分流。
- **两个旧模块在 v3 框架下跑不起来** —— `IWPhone息屏深度doze` 缺 `runtime` 声明会被
  300 秒上限强杀；`应用管理aapt` 只有 `main.bat` 入口，v3 要求 `main.sh`。

### 新增

- **浅色主题**，主题设置支持「跟随系统」，切换即时生效
- **英文语言包**，设置里可切；全部界面文案中英双语
- **首次启动激活向导** —— 通知/存储权限 → 配对 → 部署框架 → 开机自启 → 访问密钥，一页走完
- **模块图标体系** —— 模块在 `iwphone.prop` 里写 `icon="visual"` 即可获得语义图标，
  也可自带 `icon.png` 覆盖；两者都没有时按模块名哈希兜底，老模块不用改
- **首页「部署/修复框架」「完全卸载」入口**
- **设置页重排** —— 20 行 / 6 组压到 14 行 / 5 组，去掉两个没接线的假开关

### 其它

- 仓库清理：移除误提交的 Windows 缓存文件与一个 Python 字节码缓存，补上 `.gitattributes` 钉死 LF
- 模块清单 `modules.catalog.json` 升级到 schemaVersion 2，每个模块带 sha256，桌面端可校验完整性

## 安装

- 系统要求：**Android 11 及以上**（无线调试与配对码机制从 11 开始提供）
- 直接安装本页附件里的 `ShellManager-v1.3.0.apk`
- 若提示「未知来源」，请在系统设置里允许该来源安装

首次使用（App 内有引导）：

```
① 配对设备    通知栏输入配对码（配对端口由 mDNS 自动发现）
② 部署框架    点一下即可，App 内置框架包
③ 访问密钥    可选。不设也能用，但建议设一把（至少 8 位）
```

## 主要功能

**自持 adb** —— 应用内捆绑 adb，自己配对、自己连接、固定 tcp 端口、开机自启（含 JobScheduler 兜底）。

**模块管理** —— 启停、配置（模块声明 `config.prop` 即自动生成配置页）、动作按钮（`action.sh`）、
冲突检测（独占资源声明）、日志三分离、从手机存储导入安装、模块图标。

**兼容层** —— Magisk / KernelSU / AxManager 式模块可直接安装：自动适配 `module.prop`、
`service.sh`、`post-fs-data.sh`、`action.sh`、`disable` 旗标、`MODDIR`/`AXERONDIR` 环境变量；
`webroot/` 每模块 WebUI 在 App 内打开并注入 KernelSU 同构的 `ksu` 桥；自带 BusyBox（358 applet）。
安装时会给兼容性**预检**（预计兼容 / 需要 Root / 无法判断）并说明原因。

**写前快照与一键还原** —— 模块**首次写入**某系统资源前自动记录原值，
App 里点「还原」会先展示清单（当前值 → 还原值），确认后先停模块再还原。
**卸载模块不会删快照**，设置 → 历史快照可还原已卸载模块留下的改动。

**安全** —— 访问密钥可选，`chmod 600` 存放，支持改密钥免重启；
沙箱两层拦截（函数包装 + PATH 包装脚本，覆盖 `env` / `sh -c` / `command` / 变量拼路径等写法）；
安装前审计包内条目，挡 zip 路径穿越与逃逸符号链接。

> ⚠️ 关于访问密钥：不设密钥时 WebUI 对**同设备任意有网络权限的应用**开放，
> 包括以 shell 权限执行命令的 `/api/shell`。框架日志里会打一条告警。建议设置。

## 已知限制

- **绝对路径调用拦不到**：模块若用 `/system/bin/settings …`、native 二进制或 `service call`，
  沙箱不记账、也没有写前快照（安装预检会提示）
- **快照粒度**：`settings` / `appops` 是真实快照；`svc` / `pm` 是反向动词推断，不是状态快照
- **不支持** systemless 挂载、Zygisk、内核类模块 —— 免 root 环境物理上做不到
- **兼容性预检是静态扫描**，注释里的关键词也会命中（偏保守）
- **图标**：已安装的模块需要**重装一次**才会带上图标（框架读的是安装后的 `iwphone.prop`）
- **验证覆盖**：核心链路在小米 22011211C（MIUI + Android 14）上验证过；
  其它 ROM / Android 版本未验证
